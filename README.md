# cjohnmizo

Personal portfolio of **C. John Remthang** — a spatial 3D studio site for web, LMS, dashboard, and mobile work.

Live: [cjohnmizo.vercel.app](https://cjohnmizo.vercel.app) · [cjohnmizo.in](https://cjohnmizo.in)

## Stack

- Next.js 16 + TypeScript
- Tailwind CSS v4
- Three.js hero sculpture (glass monogram + personal logo)
- Contact form via `/api/contact`

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Vercel on the `main` branch. Set `NEXT_PUBLIC_SITE_URL` and contact email env vars from `.env.example`.
