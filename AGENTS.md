## ReactBits Usage Rules

ReactBits.dev-style components may be used, but only selectively.

Use **3 to 5 ReactBits-inspired effects maximum** across the whole website.

Good places to use them:

1. Hero background glow or grid
2. Hero headline text reveal
3. Project card spotlight/hover effect
4. Skills/service badge animation
5. CTA or contact button micro-interaction

Do not turn the site into an animation demo.

Avoid:

* Too many moving backgrounds
* Heavy cursor-following effects
* Animation on every card
* Overly flashy text effects
* Constant particles
* Heavy WebGL effects
* Anything that hurts mobile performance
* Anything that feels childish or distracting

All motion must respect `prefers-reduced-motion`.

## Performance Requirements

The website must remain fast.

Target Lighthouse scores:

```text
Performance: 95+
Accessibility: 95+
Best Practices: 95+
SEO: 95+
```

Mobile performance is more important than desktop performance.

Optimize:

* Images
* Fonts
* CSS
* JavaScript
* SVGs
* Animations
* Bundle size
* Layout shift
* Mobile rendering

Use:

* WebP or AVIF for raster images
* SVG/CSS for vector graphics where possible
* Width and height on images
* Lazy loading for below-the-fold visuals
* `font-display: swap`
* Minimal third-party scripts
* Reduced unused CSS
* Reduced unnecessary JavaScript

Avoid:

* Heavy animation libraries unless already used
* Large 3D assets
* Large GIFs
* Video backgrounds
* Heavy WebGL
* Animation that slows mobile devices

## Accessibility Requirements

The website must be accessible.

Check:

* Semantic HTML
* Proper heading hierarchy
* Meaningful alt text
* Button labels
* Link labels
* Form labels
* Keyboard navigation
* Visible focus states
* Color contrast
* Reduced motion support
* No content hidden only behind hover
* No meaning communicated by color alone

Decorative visuals should use empty alt text.

Meaningful visuals should use descriptive alt text.

All motion must respect:

```css
prefers-reduced-motion
```

When reduced motion is enabled:

* Disable continuous movement
* Disable large motion
* Keep content visible
* Keep UI usable
